# 雇员收取后制作 · RetainerCraftBridge

独立 Dalamud API 15 插件。**指定制作角色收完雇员后转入 Artisan 制作；开头角色的雇员再次到期后安全停工，返回开头并重新开启 AutoRetainer。** 不统计全账号是否“收完一轮”，不替换或修改原插件程序。

## 使用

需要已配置好、可单独正常工作的 AutoRetainer、Artisan 和 Lifestream。安装本仓库的插件发布包，用 `/retainercraft` 打开设置。

1. 停止原 AR 多角色模式，范围设为**仅雇员**。关闭其旧 Artisan 整合、RetainerSense / OldRetainerSense、全自动军票交付、夜间模式、一次性同步等待。结束当前自动任务。
2. 刷新角色列表，选择**开头角色**和**制作角色**。两者可以相同，均须在 AR 启用雇员轮换，且有已勾选、执行中的探险。其余角色及顺序使用 AR 原有设置。
3. 选择具体职业对应的配方及**每个制作时段的次数上限**。次数是制作动作次数，界面显示预计产量；开头到期时可能提前结束。沿用 Artisan 当前模式，不保证 HQ。首版只支持标准配方，不支持星海探索制作。
4. 点击“只检查条件”，勾选启用，再点击“开始循环”。加载、重载插件不会自动开始。
5. 插件通过 Lifestream 切到开头，开启 AR 原生轮换。指定制作角色收取成功且退出雇员交互后，停住后续换角并制作。开头再到期时，等当前普通工艺或速制批次结束，停止本次制作、退出配方菜单，再回到开头继续轮换。
6. 本时段次数用完、缺料或 Artisan 自行结束后，仍会等待开头角色。若进入制作边界时开头已经再次到期，则直接返回收雇员阶段。

## 判定与兼容限制

开头就绪只检查该角色的已选、执行中探险，沿用 AR 当前 `MultiWaitForAll`（任一/全部）及 `AdvanceTimer` 提前窗口。“全部”只指开头角色的雇员。没有任务、角色禁用/排除或数据不可读时停止交接，不把空集合当作到期。提前恢复轮换不保证当时立刻可收，实际收取仍由 AR 调度。

AR 私有的一次性 `Synchronize` 状态没有公开 getter；本插件无法读取或复刻。运行前请取消该同步等待。

制作角色到访时按 AR 当前角色的 300 秒 `Done` 视窗观察待收目标，每个目标都要求**自己的后处理握手 + 公开探险状态更新**。许可/空间不足、队列空闲或单纯 `Done` 不算成功；没有待收目标的到访不拦截。

在自己的角色后处理回调中同步执行 `DisableAllFunctions → AbortAllTasks → FinishCharacterPostprocessRequest`，撤销 AR 已经排队的下次换角。没有角色后处理通知时，只有收取证据齐全、角色正确、UI 和队列空闲才使用替代边界。该逻辑不检查其余角色是否收齐。

本流程独占 AR / Artisan / Lifestream，不支持其他自动流程、手动换角或改配方同时运行。AR 的任务清空会影响后面的其他插件后处理。结束保持多角色模式关闭；公开运行开关可能随 AR 的正常配置保存，不保证其配置文件字节不变。本插件不直接写其他插件配置，不使用私有反射。

## 停止与失败

点击“停止循环”或输入 `/retainercraft cancel`。尚未执行的开始请求也能取消。

- 停止拥有的 AR/Lifestream 队列，只释放自己的锁。已提交给游戏的登出、登录、传送不能撤回。
- 对自己提交的制作，等实际启动及当前工艺/速制批次结束间隙，调用 `Artisan.SetEnduranceStatus(false)` 一次，关闭已确认属于本次配方的标准 `RecipeNote`。正常切回收取时，要等各队列和 UI 稳定空闲后才恢复 AR；主动停止循环时不恢复 AR。
- 不使用 `SetStopRequest(true → false)`，因为它会恢复旧制作。外部暂停、其他列表、错角色、配方改变、迟到制作或未释放界面都会保持 AR 关闭，不强行恢复或重复提交。
- 换角等待 3 分钟、雇员界面退出 2 分钟、安全停工 10 分钟，原生轮换不到目标边界最多 2 小时；超时会显示失败。
- `CraftItem` 是异步入队。90 秒没观察到实际开始会失败，不重试、不恢复 AR。公开 API 不能删除 Artisan 私有队列，模糊的待执行请求可能需手动在 Artisan 清理，再重载本插件。
- **先停止循环、等空闲再卸载。** 强制卸载只能同步尽力停止拥有的动作；当前工艺可能需手动完成，尚未启动的 Artisan 请求可能仍在其队列中，日志会明确告知。
- “已开始”或“自然结束”都不证明全部物品制作成功；本插件不提供成品数量验收。

## 兼容与开发验证

静态核对版本：Dalamud API 15 / .NET 10；AutoRetainer 4.6.0.8（Ookura-Risona，`d57cb55c`）；Artisan 4.0.5.21（`e438055`）；Lifestream 2.6.0.5（`52c54fad`）。其他版本需要相同 IPC 及语义，缺接口会拒绝启动。

只分发本插件 DLL 和 manifest，使用最小公共 DTO，无原插件二进制依赖。按钮操作在 framework 线程执行，Ready 截停保持同步；唯一原生 UI 操作是安全间隙下关闭本次标准配方菜单。

仓库根目录可执行：

```powershell
dotnet build plugins/RetainerCraftBridge/RetainerCraftBridge.csproj -c Release
dotnet run --project tests/RetainerCraftBridge.Tests/RetainerCraftBridge.Tests.csproj -c Release
```

测试覆盖开头到期规则、两次连续循环、原生其他角色轮换、收取证据、握手顺序、异步启动竞态、自然结束后监视、取消、迟到任务、角色/配方所有权及卸载边界。测试使用隔离 fake host，不连接游戏。

**当前只有编译、隔离测试及静态审查记录，没有真实游戏安装、运行或用户验收记录。发布不改变这一验证边界。**
