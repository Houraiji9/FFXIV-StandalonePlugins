# BatchTrade 0.1.3 预发布

将数量上限的含义纠正为**每个交易格的上限**。0.1.2 及更早版本把它限制为整笔合计，导致总量 2516 被拆成多笔；本版按用户明确要求，一笔最多放五格，合计可以超过 999。

- 界面改为“每格数量上限（1–999）”，默认 999。
- 按背包堆数量从大到小取物品，同量保持背包顺序。背包有 518、999、999 三堆，总量 2516、每格 999 时，**一笔放入 999 + 999 + 518**。
- 每格分别遵守配置上限、该物品堆叠限制和剩余总量；第二、第三格不会扣用第一格的额度。五格不足时才继续下一笔。
- 每个交易格使用独立的源背包堆。同一源格在一笔中只使用一次，维持游戏的来源绑定规则。
- 旧版上限数值自动迁移为每格上限；十项独立延迟、物品与数量设置保留。
- 保留 0.1.2 的原始交易格／缓存同步校验、具体诊断、停止与三信号结算规则。

在插件安装器刷新原仓库并更新“批量物品交易”，用 `/batchtrade` 打开配置。确认“交易总数量”为 2516、“每格数量上限”为 999，即按上述三格规划。

仓库地址不变：

```text
https://raw.githubusercontent.com/Houraiji9/FFXIV-StandalonePlugins/main/pluginmaster.json
```

本次只更新 BatchTrade，RetainerCraftBridge 保持 0.1.0.0。目标仍为国服客户端 `2026.10.06.0000.0000`、Dalamud API 15。BatchTrade 160 项离线检查通过，完整游戏交易仍需新版客户端运行验证。
