# BatchTrade / RetainerCraftBridge 0.1.4 预发布

两个独立插件一同更新。自定义仓库地址保持不变，原版 Artisan、AutoRetainer、DailyRoutines 的 DLL 和配置文件均不由本更新替换。

## 雇员收取后制作

- 解释 AR 的 **Retainers（仅雇员）**，在界面提供完整设置路径和“打开 AR 设置”按钮。AR 默认可能隐藏模式选择器：`/ays settings → 高级设置 → 专家设置 → 显示多角色模式类型选择器`，再回主窗口选择 `Retainers`。
- 每个配方分别保存**标准制作 / 简易制作 / 跟随 Artisan 设置**。标准模式使用 Artisan 已开启的自动模式及已有求解器/宏；简易模式要求配方已解锁且支持，每批最多 99 次，不满足时不会回退成标准制作。
- 标准与简易模式由桥接器自己安排次数和取消，不修改 Artisan 全局简易开关，不向其私有连续制作队列排任务。制作角色须已处于对应职业并准备好装备；此路径不代执行 Artisan 连续制作的换装、食药、修理等预处理。
- 新增可选的**制作前从雇员取出缺少的材料**。按所设次数计算整段材料和水晶需求，扣除背包已有量，逐雇员核对真实库存后取出。须在雇员铃旁，空间和材料不足时明确停止，不降次数、不重发结果不明的请求。
- 取料六项、制作七项动作延迟分别可调；均串行等待游戏状态，同帧最多一个动作，至少间隔 100 毫秒。
- 已加载 YesAlready 时，通过其公开协作接口在本循环和清理期间暂停自动确认；结束仅移除本插件自己的暂停请求。
- 修复已接收 Endurance 停止时必须等待“第一次实际开工”的分支，首件开工前也能关闭。兼容方式尚未确认接收的私有请求仍不能由公开接口撤回；`IsBusy` 不包含全部预处理，不能把空闲或超时当作取消证明。明确标准/简易方式使用可取消的本地队列。
- 停止按钮移到窗口顶部并在清理期间保留。停止意图在框架处理本插件队列之前应用。标准制作不再开下一件；简易模式请求取消本批次；取料撤销后续步骤。已发出的游戏请求需等对应结果和自己打开的窗口收尾，手动停止不恢复 AR。

## 批量物品交易

本机诊断显示，五格 4995 个已经通过源格、缓存与数量检查，停止位于最终确认阶段。旧日志不能唯一归因于窗口实例或显示文本，也不证明交易已成功。

- 最终确认严格核对原生窗口输入的交易提示，显示节点仅用于诊断，仍保留窗口代次、接收者、对象、双方物品和金币校验。
- 完整计划已通过检查后，确认窗关闭或出现提前的完成信号，先撤销未发出的点击，进入最多 5 秒只读核对。
- **送出回执、库存精确减少本笔数量、原交易结束**三项齐全后才计入进度，再按原间隔开始下一笔；证据不足不记账、不自动重发。
- 保留每格 1–999、每笔最多五格、总量与十项独立延迟。2516 个仍按 999 + 999 + 518 放入一笔。
