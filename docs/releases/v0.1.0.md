# 0.1.0 初始预发布

两个可独立安装的国服 Dalamud API 15 插件：

- **批量物品交易（BatchTrade）**：`/batchtrade`。选择背包物品、HQ/NQ 和总数量，向开始时锁定的玩家连续赠送；对方逐笔手动确认。不依赖 DailyRoutines。
- **雇员收取后制作（RetainerCraftBridge）**：`/retainercraft`。在新界面配置开头角色、制作角色、配方和次数。AutoRetainer 轮转到制作角色并收完后，关闭多角色模式并启动 Artisan；开头角色雇员再次到期后，停止制作并恢复多角色模式，持续循环。依赖兼容的 AutoRetainer、Artisan 和 Lifestream。

无需替换现有插件 DLL。新插件默认空闲，安装后不会自动交易、换号或制作。雇员后制作通过原插件公开接口交接调度，不依赖“所有角色都已收完”的轮次判断。

## 安装仓库

在 Dalamud 设置的自定义插件仓库中添加：

```text
https://raw.githubusercontent.com/Houraiji9/FFXIV-StandalonePlugins/main/pluginmaster.json
```

然后刷新安装器并分别选择所需插件。两个 ZIP 是独立插件包，`SHA256SUMS.txt` 用于核对下载；不需要把源码压缩包放进插件目录。

## 验证范围

已进行 API 15 编译、离线状态机检查、独立静态审查和发布包核对。**尚未在真实游戏实例加载或完成交易、换号和制作验收**，所以本次标记为预发布。具体检查及客户端验证边界见仓库 `VALIDATION.md` 与各插件说明。

制作次数表示配方执行次数，不是最终物品个数；Artisan 沿用当前模式及材料设置。“观察到制作开始”不代表整批制作完成。若换号失败、指定角色不匹配、收取证据不足或 Artisan 忙碌，本轮会停止，不会尝试在其他角色上制作。
